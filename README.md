### About

我喜欢把模糊的想法做成真正能运行、能交付、也能被别人继续创造的东西。

- 正在构建轻量、快速且可定制的 AI 开发工具
- 维护开源组织 [Spark Relics](https://github.com/Spark-Relics)，收藏并打磨那些值得留下的创意
- 在桌面应用、CLI、Web、图像工作流和嵌入式设备之间持续探索
- 相信好的软件不仅要功能成立，也应该有清晰的结构、自然的交互与自己的性格
